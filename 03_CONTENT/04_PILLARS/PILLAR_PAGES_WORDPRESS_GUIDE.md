# Pillar Pages — WordPress Population Guide

## Overview

This guide shows how to create and populate all 12 pillar pages in WordPress.

**Location:** `/blueprint/pillars/`
**Parent Page:** Blueprint
**Status:** All content ready; pages need creation in WordPress

---

## WordPress Setup Instructions

### Page Creation

For each pillar below:
1. Create a new page in WordPress
2. Set **Parent** to "Blueprint"
3. Use the **slug** provided (e.g., `governance`, `economics`)
4. Copy the content section into the page body
5. Publish

### URL Structure

Each pillar will be at:
- `https://new-earth.uk/blueprint/pillars/[slug]/`

Examples:
- `https://new-earth.uk/blueprint/pillars/governance/`
- `https://new-earth.uk/blueprint/pillars/economics/`

3. **Related Links** — Add "Next Pillar" / "Previous Pillar" navigation at bottom of each page
4. **Visual Assets** — Add hero images for each pillar page (recommended)
