# New Earth Website - Local Reference Assets

This folder contains local reference imagery used for:

- review;
- comparison;
- owner selection;
- provenance investigation.

It is **not**:

- the approved Website V2 asset source;
- automatically rights cleared;
- automatically deployable;
- automatically included in public builds.

Promotion path:

```text
ASSETS_REFERENCE
    -> OWNER / CONTENT SELECTION
    -> RIGHTS / PROVENANCE VERIFIED
    -> ACCESSIBILITY USAGE DEFINED
    -> ASSETS/
    -> AUTOMATED BUILD
    -> PUBLIC DERIVATIVE
```

Source references must not be deleted merely because they are ignored by Git.
`ASSETS_REFERENCE` is local-only and must never be directly deployed.
