# Core Page Pattern V1

**Status:** PROVISIONAL CORE PAGE PATTERN - PENDING OWNER REVIEW

Established by the Vision implementation:

- A concise page hero with eyebrow, one H1 and approved opening summary.
- A centred reading column capped at approximately 820px.
- Section rhythm built from generous vertical spacing and subtle dividers.
- Serif headings with the accepted local/system-safe typography stack.
- Imagery is optional and only used when a suitable governed asset exists.
- Contextual CTAs use the existing 10px-radius button treatment.
- The layout reflows to a single readable column on smaller screens.
- The shared New Earth header, emblem lockup and five-group footer remain unchanged.

This pattern is provisional until Peter reviews and accepts the Vision page.
