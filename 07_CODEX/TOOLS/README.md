# Website Tools

## Purpose

Reusable repository-owned Website tools.

## Tool Classes

### REVIEW TOOL

Human decisions are required.

### UTILITY TASK

Deterministic local operations.

### CONTROLLED ACTION

Consequential operations requiring stronger safeguards.

## Governing Principle

Tools should be repository-owned, self-described, safe, launchable, reusable and
future-discoverable. They must not silently become public website output.

## Future Architecture

Command Centre may eventually discover tools, NEOS may understand dependencies,
GAIA may assist task preparation, and Platform Core may define shared contracts.
No such integration is implemented here.
