# Command Centre and Dashboard Boundary

## Status

WA-02A boundary decision, 2026-08-26. Planning only. No application, link,
authentication, or deployment change is authorized.

## Locked public direction

The public Command Centre information page is part of Website V2.0 at
`/ecosystem/command-centre/`. It may explain:

- Purpose and place in the New Earth ecosystem.
- Public benefits and intended outcomes.
- Evidence-based status using a conservative approved label.
- Approved public visuals and safe explanatory diagrams.

The page explains and routes to systems; it does not absorb private operational
functions.

## Separate protected systems

- The New Earth Command Centre remains a separate application.
- The New Earth Dashboard remains a separate authenticated workday application.
- A future protected portal may use a separate subdomain or another secure
  destination after architecture and security review.
- No public sitemap entry is an application route for these protected systems.

## Prohibited public material

Do not publish:

- Credentials, tokens, usernames, email addresses, or authentication details.
- Internal controls, private infrastructure, ports, hostnames, IP addresses, or
  deployment information.
- Financial information, administrative functions, private records, or sensitive
  architecture.
- Screenshots or diagrams that expose protected interfaces or operational data.
- Unverified technical, security, readiness, performance, or company claims.

## Future links

Any future "Open Dashboard" or equivalent link requires separate:

1. Security and threat review.
2. Authentication and authorization design.
3. Privacy and data review.
4. Accessibility and usability testing.
5. Failure-state and session testing.
6. Release approval and rollback plan.

Until all gates pass, no protected-system link is added to public navigation.

## Ownership and review

Public system copy requires the named system owner and New Earth review. Status
claims must be evidence-based, dated, and conservative. The private Command
Dashboard remains outside this repository's public website application scope.
