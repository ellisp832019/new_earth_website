# Homepage V2 Offline Preview

Open `homepage-v2-preview.html` directly in a browser. The preview uses only
its sibling CSS and JavaScript plus the existing repository homepage hero via a
relative path. It has no external fonts, scripts, feeds, trackers, embeds, or
network dependencies. Below-the-fold imagery uses existing tracked repository
assets with explicit dimensions and lazy loading; no untracked reference image
is used. Missing subject-specific imagery is represented by labelled offline
placeholders rather than unrelated assets.

Review at approximately 320px, 375px, 768px, 1024px, and 1440px. Test the skip
link, mobile menu, keyboard focus, links with JavaScript disabled, ecosystem
text equivalent, image alt text, production placeholders, and reduced-motion
preference. External application cards are safe placeholders only.
