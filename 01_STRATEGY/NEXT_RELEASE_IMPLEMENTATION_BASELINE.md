## Purpose

The current website at this commit is the approved visual, functional and
content implementation baseline for the next major release.

WA-00 through WA-05 define the approved future direction.

They do NOT authorise destructive replacement of the existing website before
the proposed replacement has been implemented, reviewed and approved.

## Core Implementation Rule

CURRENT BASELINE
→ ADD NEW CAPABILITY
→ AUTOMATED CHECKS
→ LOCALHOST REVIEW
→ COMPARE WITH EXISTING
→ FIX
→ PETER APPROVAL
→ ONLY THEN REPLACE / MOVE / REMOVE OLD PRESENTATION
→ RECHECK
→ COMMIT

## Non-Destructive Development Rule

Until a replacement is explicitly approved:

- existing navigation remains
- existing homepage remains
- existing routes remain
- existing visual identity remains
- existing sections remain
- existing public-safe assets remain
- existing project presentation remains
- existing Blueprint/Pillar presentation remains
- existing footer remains
- existing working functionality remains

New future-release capabilities should first be added alongside the existing
site wherever practical.

## Replacement Gate

Existing presentation may only be removed, replaced or materially rearranged when:

1. the replacement has been implemented;
2. it works on localhost;
3. relevant automated checks pass;
4. desktop/tablet/mobile behaviour has been reviewed;
5. accessibility/public-private boundaries have been reviewed;
6. Peter has visually approved the replacement;
7. the replacement does not lose valuable existing content or capability.
