## Official Guidance Used

W3C WAI image guidance distinguishes informative, decorative and functional image
purposes and requires an equivalent text alternative. WCAG 2.2 SC 1.1.1 is the
implementation target; prerecorded media requires captions where applicable.
Official references: https://www.w3.org/WAI/tutorials/images/,
https://www.w3.org/TR/WCAG22/ and
https://www.w3.org/WAI/WCAG22/Understanding/captions-prerecorded.

## Accessibility Classification

Informative imagery needs concise purpose-led alt text; decorative imagery uses
empty alt in implementation; functional imagery names the action; complex diagrams
need concise alt plus visible structured text; logos need appropriate brand name
and function. Text in images is not a substitute for HTML text.
