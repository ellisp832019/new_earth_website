## Verified purpose

Command Centre is being developed as a human-facing place to discover, open,
navigate and observe parts of the New Earth technical ecosystem.

## Why it exists

As projects, repositories and tools grow, navigating each one separately can
become difficult. Command Centre aims to reduce that friction without
removing human control or erasing the boundaries between specialist systems.

## What it is

The current repository supports a thin Windows desktop shell for discovery,
launch, navigation, observation, summarisation, notification and bounded
orchestration. It presents access to other systems rather than replacing the
capabilities they own.

## Current state

The project is in active development. Its current source includes a registry,
discovery services, launch-target resolution, status surfaces, command-palette
presentation and read-only adapters for selected NEOS and GAIA-related views.
This page is a local preview and does not claim public deployment or finished
ecosystem integration.

## What exists today

- A Windows desktop shell and application registry.
- Repository and application discovery with launch-target resolution.
- Navigation, health/status and audit-oriented surfaces.
- A deterministic command palette for catalogued actions.
- Read-only presentation of selected routed NEOS results and governance
  information, with unavailable states when services or mappings are absent.

## Evidence

The evidence is current source implementation, repository documentation and
focused tests covering discovery, safe action boundaries, command handling,
NEOS routing and governance presentation.

The available ecosystem roadmap is conceptual and contains broader
aspirational language, so it is not used as public evidence.

## Current limitations

Command Centre does not own engineering intelligence, AI reasoning,
project-domain behaviour or arbitrary shell execution. NEOS, GAIA and each
project application retain their own responsibilities. Not every project is
integrated, local configuration affects availability, and packaging/runtime
hardening remains open development work.

## Relationship to NEOS

NEOS remains the owner of engineering intelligence. Command Centre can route
and present selected NEOS information; it does not recompute the underlying
engineering result.

## Relationship to Dashboard

New Earth Dashboard is a separate organisational working interface. It is not
embedded in this public project page and its private controls are not part of
Command Centre’s public description.

## Relationship to New Earth

Command Centre is one coordination surface within the wider New Earth
ecosystem. Specialist systems remain distinct, and the shell helps people
reach or observe them without claiming ownership of their domain functions.

## Next controlled direction

Continue runtime, packaging and integration validation, with deeper NEOS and
GAIA presentation added only where the underlying evidence and boundaries
remain clear.
