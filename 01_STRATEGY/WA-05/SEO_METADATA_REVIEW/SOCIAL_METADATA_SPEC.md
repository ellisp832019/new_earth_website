# Social Metadata Specification

For each publishable route, generate `og:title`, `og:description`, `og:url`,
`og:type`, `og:image`, `og:image:alt` where supported and `og:site_name`.

- Use `{CANONICAL_ORIGIN}` until the preferred HTTPS host is verified.
- Default site name candidate: `New Earth`.
- Use page-specific title and description, not keyword lists.
- Use a representative rights-cleared image only after WA-05H review.
- Keep focal subjects inside a safe area for common social crops; do not put
  essential wording in the image.
- Core pages use `website`; Journal entries use `article` when published.
- Pillar, system and creator-lane cards require content, maturity and rights review.
- Do not invent social handles or accounts.
