# Website V2 Content Acceptance Checklist

- [ ] Named content owner and last review date recorded.
- [ ] Source and evidence class are recorded for every material claim.
- [ ] Facts, history, vision, principle, research, concept, prototype, development, pilot, availability, and uncertainty are not conflated.
- [ ] Status and uncertainty are stated honestly.
- [ ] Audience and primary purpose are clear.
- [ ] Headings are readable, descriptive, and logically ordered.
- [ ] Language is natural public voice, not internal planning language.
- [ ] Copy is accessible, plain, respectful UK English.
- [ ] CTA describes a useful next action and has meaningful link text.
- [ ] No invented functionality, outcomes, readiness, users, or availability.
- [ ] No unsupported partnership, ownership, endorsement, or integration claim.
- [ ] No credentials, private paths, personal data, or protected system details.
- [ ] Legal, health, safety, financial, technical, or safeguarding issues were escalated where required.
- [ ] Internal links use approved canonical routes and resolve.
- [ ] Images are relevant, permissioned or appropriately marked as conceptual.
- [ ] Image alternatives and text alternatives for diagrams are present.
- [ ] Owner approval and next review date are recorded.
