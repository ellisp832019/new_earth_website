# Website V2 Launch Dependency Map

## Controlled Route

`WA-05E1`
-> `WA-05F Accessibility`
-> `WA-05G SEO & Metadata`
-> `WA-05H Assets / Rights / Alt Text`
-> `WA-05 Specialist Closure`
-> `12 Pillars Content Production`
-> `WordPress V2 Staging Build`
-> `Live Runtime Verification`
-> `Final Owner Review`
-> `Controlled V2 Launch`

WA-05E1 closes the initial publication scope. It does not close company,
privacy, runtime or professional-review inputs required for launch.

## Outside Initial Launch Scope

The following remain future activation gates and are not authorised by the
initial informational baseline:

- Commerce and payments
- Accounts and subscriptions
- Native community
- GAIA interaction
- Wellbeing or BioCalm data
- MicroGrow commercial sales
- Donations or investment functionality
