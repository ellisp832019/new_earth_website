# Core Page Approval Checklist

## Scope

This checklist covers the six WA-05C core-page drafts: Vision, Manifesto,
Blueprint, Ecosystem, About, and Get Involved. It is an approval gate for
public content only and does not authorise WordPress publication.

## Per-page checks

- [x] One H1 and a logical heading hierarchy.
- [x] Opening summary is clear to a newcomer and specific to the page.
- [x] Page purpose, evidence class and unresolved dependencies are recorded.
- [x] Public claims are supported, qualified or clearly marked as developing.
- [x] British English, approved terminology and consistent voice are used.
- [x] Internal links resolve to approved canonical routes.
- [x] CTA is restrained, useful and appropriate to the page purpose.
- [x] Image brief includes truthful subject guidance and suitable alternative text.
- [x] No founder, partner, legal, technical, health, financial or outcome claim
  is published without the required owner review.

## Page-specific gates

- [x] Vision remains an invitation and direction, not a promise of completion.
- [x] Manifesto is recorded at `/manifesto/` as a secondary public route.
- [x] Blueprint presents a developing framework, not a universal finished plan.
- [x] Ecosystem keeps public explanations separate from protected applications.
- [x] About contains no unapproved founder history, biography or company claim.
- [x] Get Involved preserves the approved independent New Earth Builders wording,
  external URL and external-link treatment.
